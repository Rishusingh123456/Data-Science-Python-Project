# Data-Science-Python-Project
# Data Science with Python Internship

## Overview

This repository contains my complete six-week Data Science with Python internship work.

## Dataset

Diabetes Health Indicators Dataset

## Weekly Tasks

### Week 1 – Data Cleaning & Preprocessing
Data acquisition, cleaning, duplicate removal, outlier analysis and preprocessing.

### Week 2 – Exploratory Data Analysis
Statistical analysis and visualization of important diabetes-related health indicators.

### Week 3 – Unsupervised Learning
K-Means clustering, cluster evaluation using Elbow Method and Silhouette Score, and PCA visualization.

### Week 4 – Supervised Learning
Implementation and evaluation of Logistic Regression and Random Forest classification models.

### Week 5 – Deep Learning
Development of a neural network using TensorFlow/Keras for diabetes classification.

### Week 6 – Integrative Capstone
Integration of the complete data science workflow and comparison of machine learning and deep learning approaches.
